<div className="flex flex-1 items-center justify-center bg-background text-foreground">

| Class | Token |
| --- | --- |
| `bg-background`, `text-foreground` | panel colors |

| `font-sans` / `font-mono` | Inter / JetBrains Mono |

Default Tailwind utilities (`flex`, `p-4`, `text-sm`, …) work as usual. Use complete class names in source — Tailwind scans files as text and will not see interpolated strings like `` `bg-${color}` ``.
