The warning is a React state update after `Editor` has already unmounted. Chrome’s `%s` is again just an unfilled format placeholder — the real text is “cancel subscriptions in a **useEffect cleanup**.”

`usePort()` (the hook on the stack) connected to the service worker and did this with no cleanup:

```ts
nextPort.onDisconnect.addListener(() => setPort(undefined));
```

Closing the DevTools panel, reloading the extension, or HMR disconnects that port after `Editor` is gone, so `setPort` runs on an unmounted component.

`usePort` now:

- ignores disconnects after unmount
- disconnects the port and clears the reconnect timer in the effect cleanup
- reconnects only while the panel is still mounted

Store subscribers also ignore updates after unsubscribe, so a late `animationstart` / `clear` cannot call `setState` on a dead `Editor`.
